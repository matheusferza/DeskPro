# DeskPro

DeskPro é uma aplicação para controle de entregas e acompanhamento de pedidos, com importação de dados em Excel e organização por status.

## Funcionalidades
- Cadastro e organização de registros
- Importação de planilhas Excel
- Cálculo automático de status
- Controle de entregas em prazo, atrasadas e concluídas

## Requisitos
- Python 3.10+
- Dependências do arquivo `requirements.txt`

## Como executar
1. Ative o ambiente virtual do projeto
2. Instale as dependências:
   ```bash
   python -m pip install -r requirements.txt
   ```
3. Execute a aplicação:
   ```bash
   python main.py
   ```

## Testes
```bash
python -m pytest -q
```
